# ai_logs/ — AI Copilot Interaction Records

**This is one of the most important artifacts for demonstrating the scientific + AI-assisted process.**

## Structure
- `prompts/` — Full or summarized prompts used
- `decisions/` — What the team decided after receiving AI output + rationale

## Logging Standard (required)
For each significant AI use:
1. Save the prompt (or a clean version)
2. Record model used + timestamp
3. Summarize response
4. Document decision and impact

Example filename: `day01_requirements_prompt.md`

## Why This Matters
- Shows how AI was used as a tool, not a black box
- Enables reproducibility of thought process
- Provides evidence for academic evaluation
