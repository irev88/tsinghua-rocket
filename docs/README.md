# docs/ — Formal Project Deliverables

This directory contains polished, academic-style documentation for each phase of the project.

## Organization
Each numbered folder corresponds to a day/theme from the 10-day blueprint.

- Use consistent section structure: Executive Summary, Requirements/Approach, Analysis & Results, Trade-offs, Conclusions & Open Issues.
- Include figures from `../figures/`.
- Cross-reference `ai_logs/`, `analysis/`, and `engineering_notebook.md`.

## Naming Convention
- `topic_report.md` or `deliverable_name.md`
- Supporting files: `appendix_*.md`, `data_table.csv`

See `10_DAY_BLUEPRINT.md` for day-by-day deliverables.

- Clear hypotheses
