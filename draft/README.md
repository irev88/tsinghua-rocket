# draft/ — Temporary Brainstorming & Work-in-Progress

**WARNING**: All content in this directory is **ephemeral**.  
It will be reviewed, curated, moved to permanent locations, or **deleted** by the end of the project (Day 10+).

## Purpose
- Capture raw thinking before it is polished
- Record early work plans and daily intentions
- Store "half-baked" ideas that might become novel contributions
- Document dead-ends (valuable for scientific honesty)
- Brain dumps from AI sessions that need digestion

## Guidelines for Use
- Name files descriptively with dates when possible
- Use `brainstorm/`, `work_plans/`, and `early_notes/` subfolders
- Never reference draft files from final deliverables without first moving content
- At project end: curate the best ideas into `docs/`, `analysis/`, `ai_logs/`, etc.

## Contents (Initial)
- `work_plans/` — Daily and weekly planning artifacts
- `brainstorm/` — Novel concepts and wild ideas
- `early_notes/` — First-pass calculations, assumptions, literature notes
