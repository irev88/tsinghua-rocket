# Early AI Prompt Templates
**Date**: 2026-07-18

These are starter templates. Improve over time.

## General Engineering Copilot Template
```
Role: You are a senior aerospace engineer with 20 years experience in launch vehicle design, currently acting as subsystem mentor.

Current design state:
- [paste key parameters]

Please [specific task].

Requirements:
- State all assumptions explicitly
- Provide quantitative outputs where possible
- Identify at least two risks or uncertainties
- Suggest 2-3 concrete next analysis steps
- If code is involved, provide clean, commented Python
```

## Trade Study Template
"Perform a structured trade study between [Option A] and [Option B] for [aspect]. Use a weighted decision matrix. Include sensitivity to the top 3 weighting factors."

## Novelty Injection
"Besides conventional solutions, suggest 2–3 emerging or unconventional approaches that a typical team might overlook. For each, give rough feasibility assessment."
