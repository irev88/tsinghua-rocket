# Daily Rhythm & Checklist Template (Draft)
**Use this as a living template each day**

## Morning (15-20 min)
- [ ] Read yesterday's engineering notebook entry
- [ ] Review open questions from previous day
- [ ] Formulate 1-2 hypotheses or questions for today
- [ ] Quick scan of relevant `ai_logs/`

## Core Work Block
- Primary technical task
- Secondary exploration

## Structured AI Session (45-60 min)
**Prompt Template** (copy-paste and customize):
```
You are an experienced aerospace systems engineer and mentor.

Current vehicle baseline: [paste key numbers]

Task: [specific ask — e.g., generate alternatives, critique, write code, run trade study in text form]

Constraints: [list]
Novelty request: Suggest at least two non-obvious or emerging-technology approaches.

Output format: 
1. Key assumptions
2. Quantitative comparison table
3. Pros/cons + risks
4. Recommended next analysis step
5. 3-5 prompt ideas I can use next
```

## Afternoon Synthesis (30-45 min)
- [ ] Update mass budget / key parameters
- [ ] Generate at least one figure
- [ ] Write 300-500 words of rationale

## End-of-Day Ritual (20 min)
- [ ] Update `engineering_notebook.md`
- [ ] Create or append to `ai_logs/decisions/dayXX_*.md`
- [ ] Commit changes with meaningful message
- [ ] Write 3 bullet "what I learned / surprised me"

## Metrics to Track (optional)
- Number of AI prompts logged
- Number of alternatives considered
- Uncertainty ranges narrowed
- Novel idea explored today?
