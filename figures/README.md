# figures/

All generated figures and diagrams.

## Organization
- `dayXX/` or by topic (e.g., `trades/`, `trajectory/`)
- Prefer vector (PDF/SVG) + high-res PNG
- Include the generating script name in filename or metadata
- Add captions in corresponding report documents

## Recommended Tools
- Matplotlib / Plotly (code-driven)
- Draw.io / Excalidraw for architecture diagrams (export clean)
- Inkscape for final polish

**Do not commit large raw image dumps** — only final publication-quality figures.
