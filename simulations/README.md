# simulations/

Simulation models and output data (not source code — code lives in `code/`).

## Subdirectories
- `trajectory/` — Ascent, descent, landing profiles
- `aero/` — Aerodynamic databases
- `structural/` — Loads, stress, thermal

Store:
- Input decks / config files
- Result CSVs / NPZ
- Summary plots (also copy key ones to `figures/`)

## Reproducibility
Every simulation directory should have a `README.md` describing how to re-run.
